<details>
<summary>В чем разница между списком и кортежем</summary>

- Список изменяемый, кортеж нет. 
- У списка длина может увеличивать, а у кортежа нет. 
- Кортежи более производительны и занимают меньше памяти, чем списки, так как у списков под запасом еще хранится память
- Кортеж - хешируемый, список нет
- Список имеет большое кол-во методов для изменения, у кортежа всего 2 - это index и count для подсчета вхождений.

Я бы использовал список, если данные наши будут обновляться, а кортеж бы использовал для тех данных которые написали один раз и больше бы не использовали

</details>

<summary>В чем разница между “is” и “==”?</summary>

Двойное равенство сравнивает значение объектов, а is сравнивает ссылки в памяти. Например можно проверить через id

```.py
a = [1,2,3]
b = a
c = [1,2,3]

print(a == b)   # True
print(a == c)   # True  
print(a is b)   # True
print(a is c)   # False
```

<summary>Что делает функция range</summary>

Он генерирует последовательность чисел. И у него 3 параметра: start (начало отсчета), stop (конец отсчета), step - это шаги.

Если мы укажем лишь цифру условно 5, он выведет число от 0 до 4. Если мы укажем 2 параметра, то первый он возьмет start а второй stop.
</details>

<details>
<summary> Что такое pickle?</summary>

pickle - это модуль, который превращает объект в байтовый поток и потом возвращает обратно в объект, но у него есть проблемы с безопасностью и мы можем случайно загрузить вредоносный код через pickle.load() - а более безопасный вариант для обмена данными это json

```.py
import pickle

# Сериализация (упаковка)
data = {"name": "Alice", "age": 30}
with open("file.pkl", "wb") as f:
    pickle.dump(data, f)

# Десериализация (распаковка)
with open("file.pkl", "rb") as f:
    loaded = pickle.load(f)
    print(loaded)  # {'name': 'Alice', 'age': 30}
```

</details>
