Функция `print` — это встроенная функция Python, которая отображает сообщения на экране для взаимодействия с пользователями.

[Переменные](./basic/1_variables.py) - представляет собой контейнер, в котором мы можем хранить какие-либо данные, например, строки или числа. В Python мы объявляем переменную просто записав ее имя, а через оператор = указываем ее значение, а если мы хотим обновить значение, то просто пишем снизу новое значение. Как и в js значение переменных можно [`+, -, *, /, %, **`](./basic/2_math.py), однако отличием является `//`, где делит одно число на другое и округляет результат вниз, отбрасывая остаток, а также есть и другие операции - [строки и спец.символы](./basic/3_string.py), [логические операторы](./basic/4_logical.py), [none]('./basic/5_none.py')

В Python есть строгая типизация объекта, другими словами мы не можем сложить или вычесть если у левого операнда например число, а у правого строка. Мы получим ошибку, чтобы устранить данную проблему необходим преобразовать их в один тип. Чтобы преобразовать строку используем метод str(variable), а если строку в число, то исп int(variable), а для преобразование в число с плавающей точкой используется функция float

```.py
print('123' + '456')           # '123456'
print('abc' + str(1))          # abc1
print(int('1') + int('2'))     # 3
float('1.1') + float('2.1')    # 3
```

Для преобразование в число с плавающей точкой используется функция float
```.py
print(float('12.1'))    # 12.0
print(float('12'))      # 12.0
print(float('1.1') + float('2.1'))  # 3.2
```

Если мы хотим узнать к какому типу принадлежит то или иное свойство, то исп type(variable)
