В начале необходимо:

- [Установить пайтон](https://www.python.org/downloads/);
- Проверить версию через `python --version`, сейчас используется 3.14.7
- Установить популярные расширения Python (debugger, pylance, environments) в вс-коде, а также autopep8 (Shift + ctrl + p and Format document) для форматирования кода
- Если мы работаем с терминалом, то в начале пишем слово python а затем уже print("Hello world"), или заходим на файл и в правом углу будет кнопка run нажимаем на него либо мы можем установить shortcut с помощью => Shift + ctrl + p => Open Keyboards ShortCats => Run Python File (Keybinding поля) пишем свой shortcut - у меня `ctrl p`
- Комментарии указываются двумя способами: # (analog //) и """some value""" (analog /*... */)
