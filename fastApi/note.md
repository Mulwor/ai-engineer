Инструкция:

1. Для того, чтобы установить FastAPI на проект нужно ввести команду - `pip install fastapi[all]`, а для запуска его нужен будет сервер и для этого будет использовать uvicorn - `pip install uvicorn[standard]`  

Команда: `pip install fastapi[all] uvicorn[standard]`

2. Для запуска приложения используем команду - `python -m uvicorn main:app --reload` в папке где все установили, где
  - `main` - указывает на файл main.py.
  - `app` - указывает на объект FastAPI, который мы создали.
  - `--reload`: перезагружает сервер при каждом клике
  
Если есть [архитектура](./02_structure/note.md) какая-то `python -m uvicorn app.main:app --reload`

3. Настройки вирт.окружения. - Для того чтобы обеспечить изоляцию зависимостей проекта и избежать конфликтов между библиотеками, все установленные пакеты должны находиться в виртуальном окружении. Виртуальное окружение – это независимая среда, в которой ваш проект использует только те библиотеки, которые ему нужны, без влияния на глобально установленные пакеты в системе.

Переходим в конкретную папку и пишем команду `python -m venv venv`, где venv - имя папки, в которой будет создано виртуальное окружение.  А для активации вирт.окружения пишем команду:
  - Команд.строка - `venv\Scripts\activate`
  - PowerShell то `.\venv\Scripts\Activate.ps1`
  - MacOS/Linux то `source venv/bin/activate`

После активация (будет отмечено venv) устанавливаем все необходимые пакеты, указанные в файле requirements.txt => `pip install -r requirements.txt`, что гарантирует, что все зависимости будут установлены в изолированной среде, и ваш проект не будет конфликтовать с другими проектами или системными библиотеками.

4. Pydantic — это Python-библиотека для выполнения валидации данных. Он используется для поддержки редактора (автодополнения и проверка кода), проверки типов, валидации данных, документирования API
