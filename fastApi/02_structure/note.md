Структура фаст-апи состоит из нескольких каталогов:

```.py
project_name/
├── app/
│   ├── __init__.py
│   ├── main.py
│   └── models/
│        └── __init__.py
└── requirements.txt
```

- `app` -  содержит основной модуль приложения и вложенные пакеты для моделей и маршрутов. Внутри него находится 
  - `main.py` - точка входа нашего приложения и будут определяться маршруты и запуск сервера;
  - Каталог `models` используется для размещения моделей данных, например, моделей Pydantic для обработки запросов и ответов.
- `requirements.txt` - будут указаны все зависимости, такие как FastAPI и Uvicorn

Также существуют и другие виды структур:
- Функциональная структура
- Сервисно-ориентированная структура
- Слойная структура

Для запуска со структурой - python -m uvicorn app.main:app --reload
